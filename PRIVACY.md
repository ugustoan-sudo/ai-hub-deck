# ai-hub-deck プライバシー ポリシー

最終更新日：2026年11月15日

ai-hub-deck（以下「本アプリ」）は、作成者本人だけが使う個人用ダッシュボードです。

## 取得する情報

本アプリは、作成者本人が許可した Google アカウントについて、Google ToDo（Google Tasks）の内容（タイトル、期限、メモ、リスト名）を読み取り専用で取得します。利用する権限は `https://www.googleapis.com/auth/tasks.readonly` のみです。

## 利用目的

取得した情報は、作成者本人のダッシュボード画面に ToDo を表示する目的にのみ使います。

## 保存場所と保存期間

- 取得した情報と認証情報は、作成者が管理する非公開ネットワーク内の機器にのみ保存します。
- 表示用のデータは、取得のたびに最新の内容で置き換えます。

## 第三者への提供

取得した情報を第三者に提供、販売、共有することはありません。広告や分析の目的にも使いません。

## Google ユーザーデータの取り扱い

本アプリによる Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に従います。

## アクセスの取り消し

Google アカウントの「サードパーティ製のアプリとサービス」の画面から、いつでも本アプリのアクセス権を取り消せます。

## お問い合わせ

本アプリの同意画面に表示されるサポート用メールアドレスまでご連絡ください。

# ai-hub-deck Privacy Policy (English)

Last updated: November 15, 2026

ai-hub-deck is a personal dashboard used only by its author.

- **Data accessed:** the contents of the author's own Google Tasks (title, due date, notes, list name), read-only, using only the `https://www.googleapis.com/auth/tasks.readonly` scope.
- **Purpose:** to display those tasks on the author's own dashboard. Nothing else.
- **Storage:** the data and the authorization credentials are stored only on devices inside the author's private network. Display data is replaced with the latest contents on each fetch.
- **Sharing:** the data is never provided, sold or shared with any third party, and is not used for advertising or analytics.
- **Google user data:** the app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
- **Revoking access:** access can be revoked at any time from the Google Account page for third-party apps and services.
- **Contact:** the support email address shown on the app's consent screen.
